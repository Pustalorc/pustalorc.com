# pustalorc.com

Code for my [personal site](https://pustalorc.com), the front door to the domain. My portfolio lives at
[dev.pustalorc.com](https://dev.pustalorc.com).

## Development

- `npm run dev`: local dev server.
- `npm run build`: lint (`astro check`, ESLint, `tsc`) and build to `dist/`.
- `npm test`: build, then check the built site in `dist/` with `node --test`.
